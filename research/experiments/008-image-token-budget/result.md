# E008 result — Image-token budget

## Interpretation

Rejected. Every 320 px fixture realized only 70–80 image tokens at configured caps 128/192/256/768, so the cap never bound. The result explains why E001 browser resizing did not move latency, but the mechanism is the opposite of our initial assumption: the controlled live inputs are already below 128 tokens.
