# Code of conduct

We want this project to be a respectful, rigorous place to collaborate.

Contributors are expected to communicate constructively, critique evidence rather than people, welcome good-faith questions, respect privacy, and acknowledge uncertainty. Harassment, discrimination, intimidation, doxxing, and publication of private data are not acceptable.

Project maintainers may edit or remove contributions that violate these expectations and may temporarily or permanently restrict participation. Report conduct concerns privately to the repository owner through the contact method on their GitHub profile.
