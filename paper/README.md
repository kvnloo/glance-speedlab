# Paper

`PAPER.md` is the working technical report accompanying Glance Speedlab. `ARTIFACTS.md` maps every central quantitative claim to a committed aggregate and experiment interpretation. `references.bib` contains the current bibliography.

Before submission or archival release:

1. Reproduce the paper tables from a clean checkout.
2. Complete a larger labeled live-camera evaluation.
3. Decide whether the operational smoke-test section belongs in the final manuscript or only the artifact appendix.
4. Add the final repository URL, release tag, and archival identifier to `CITATION.cff`.
5. Disclose and review the documented coding-agent assistance according to the target venue’s policy.

The Markdown report is canonical until a typeset version and generation source are added together. Do not hand-edit a generated PDF without updating `PAPER.md`.
